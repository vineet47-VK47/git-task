# git-task
This project is a simple website created using HTML, CSS, and JavaScript.Each technology is managed in separate branches and merged into the main branch after completion

## Technologies used
- HTML → Structure of the website

- CSS → Styling and layout design

- JavaScript → Interactivity and functionality
